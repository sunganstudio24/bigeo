# 아요의 비거 날리기

진주 비거 체험관 제안용 교육 게임 데모입니다. 초등 1~3학년이 비거 부품을 골라 날려 보면서 날개 크기, 무게, 무게중심이 비행에 주는 영향을 체험합니다. 쉬운 모드는 한 판 1~2분, 도전 모드는 2~3분입니다.

외부 라이브러리와 인터넷 연결 없이 동작합니다.

## 파일 구성

| 파일 | 내용 |
|---|---|
| `index.html` | 시작 파일 |
| `style.css` | 버튼·글자·배치 |
| `game.js` | 게임 코드(화면별 함수: title / story / build / flight / result / quiz) |
| `data.js` | **문구와 수치 — 코드를 몰라도 여기만 고치면 됩니다** |
| `assets/hamo/` | 하모 이미지 |
| `assets/ayo.png` | 아요(하모 프렌즈의 삵) 이미지. 불러오지 못하면 도형으로 그립니다 |
| `assets/bg/` | 배경 사진(`title.jpg`, `story.jpg`, `flight.jpg`). 없으면 기존 그림 배경을 씁니다 |

## 로컬에서 실행하기

`index.html`을 더블클릭해서 Chrome이나 Edge로 열면 바로 실행됩니다.

체험관 PC에서는 전체 화면 키오스크로 띄우면 좋습니다.

```
chrome --kiosk "file:///C:/경로/ayo-bigeo/index.html"
```

## GitHub Pages로 배포하기

1. GitHub에서 새 저장소를 만들고 이 폴더의 파일을 모두 올립니다. `index.html`이 저장소 맨 위에 있어야 합니다.
2. 저장소의 **Settings → Pages**로 들어갑니다.
3. **Source**를 `Deploy from a branch`로, **Branch**를 `main` / `(root)`로 고르고 **Save**를 누릅니다.
4. 1~2분 뒤 `https://계정이름.github.io/저장소이름/` 주소로 접속합니다.

모든 경로가 상대경로라서 따로 고칠 설정은 없습니다. GitHub Pages는 파일 이름의 대소문자를 구분하므로 이미지 파일 이름을 바꿀 때는 `data.js`와 똑같이 맞춰 주세요.

## data.js 수정 방법

메모장이나 VS Code로 `data.js`를 열어 고치고 저장한 뒤, 브라우저를 새로고침합니다. 따옴표와 쉼표는 지우지 마세요.

| 바꾸고 싶은 것 | 고칠 곳 |
|---|---|
| 이야기 화면 하모 대사(한 줄씩 넘어감) | `STORY.lines` |
| 결과 화면 맨 아래 문구, 최고 기록 대사 | `TEXT.resultNote`, `TEXT.bestExtra` |
| 퀴즈 뒤 장소 안내 | `PLACE_INFO` |
| 사진 위 흰 막, 채도 | `BG_OVERLAY`, `BG_DESATURATE` |
| 비행 화면의 땅·강 높이(사진이 함께 움직임) | `GROUND_Y` |
| 사진 위 언덕·모래밭의 불투명도 | `FLIGHT_HILL_ALPHA`, `FLIGHT_SAND_ALPHA` |
| 사진 파일 이름과 보이는 위치 | `BG_PHOTOS` |
| 아요 크기와 앉는 자리 | `AYO_SIZE` |
| 조립 화면 첫 선택값 | `CONFIG.defaults` |
| 결과 화면 하모 대사 | `FEEDBACK` |
| 퀴즈 문제 추가·수정 | `QUIZ` |
| 상황별 하모 이미지 | `HAMO_IMG` |
| 버튼·제목 등 나머지 문구 | `TEXT`, `GRADE_TEXT` |
| 날개·몸통 수치 | `CONFIG.wings`, `CONFIG.bodies` |
| 비행 느낌(속도, 하강, 뒤집힘) | `CONFIG.flight` |
| 등급을 나누는 거리 | `CONFIG.grades` |
| 자동 리셋 시간 | `CONFIG.idleResetSeconds` |

수치를 바꾼 뒤에는 아래 검사를 꼭 다시 실행하세요.

## 도전 모드: 진주성 60초

타이틀에서 모드를 고릅니다. 쉬운 모드는 조립 후 발사만 하고, 도전 모드는 60초 동안 부품을 찾아 비거를 만듭니다. 한 판은 2~3분입니다.

### 단계(data.js `STAGES`에서 기능을 켜고 끕니다)

| 기능 | 1단계 | 2단계 | 3단계 |
|---|---|---|---|
| 숨김 장소 | 8곳(꽝 2) | 9곳(옛 책 1) | 12곳(꽝 1, 옛 책 1) |
| 부품 상태 | 없음 | 있음 | 있음 |
| 마을 사람 힌트 | 없음 | 1명 | 1명 |
| 물물교환 | 없음 | 없음 | 2명 |
| 돌발 이벤트 | 없음 | 없음 | 1~2개 |
| 발사 | 자동 | 당겨서 쏘기 | 당겨서 쏘기 |
| 배 두드리기 | 없음 | 없음 | 3번 |
| 목표 거리 | 90m | 100m | 110m |

- 처음에는 1단계만 열리고, 성공하면 다음 단계가 열립니다. 열린 단계는 브라우저에 저장됩니다.
- **단체 체험용 설정:** 타이틀 로고를 빠르게 5번 누르면 단계 고정 메뉴가 나옵니다. 고정하면 [도전 모드]가 바로 그 단계로 갑니다. 진행과 도감 지우기도 여기 있습니다.
- 쉬운 모드는 타이틀 버튼으로 [자동 비행]과 [조종하기]를 고릅니다. 기본은 자동 비행입니다.

### 조종

- **당겨서 쏘기:** 비거를 누른 채 왼쪽으로 끌었다 놓습니다. 끈 길이가 세기입니다. 왼쪽 수평으로 당기면 약 30도로 가장 멀리 갑니다. 아래로 기울이면 높게, 위로 기울이면 낮게 쏘고(10~60도), 오른쪽으로 밀면 취소됩니다. PC는 위/아래 = 각도, 좌/우 = 세기, 스페이스 = 발사입니다.
- **배 두드리기(3단계):** 비행 중 화면을 누르거나 스페이스를 누릅니다. 내려가는 중에 더 잘 듣고, 무거운 몸통일수록 약합니다.
- **상승 기류:** 남강 위 아지랑이를 지나면 자동으로 살짝 떠오릅니다. 위치는 판마다 같습니다. 쉬운 모드 자동 비행에는 없습니다.
- 쇠 몸통이나 뒤 무게추는 어떻게 조종해도 추락합니다.

### 그 밖의 요소

- **처음 보는 요소 안내:** 그 자리에서 손가락과 한 줄 안내가 나오고, 누르면 계속합니다. 안내 중에는 제한 시간도 멈춥니다. `TUTORIALS.enabled`로 끄고, `TUTORIALS.resetOnTitle`로 타이틀 복귀 때 다시 보여 줄지 정합니다.
- **소리:** 효과음은 코드로 만듭니다. 타이틀에서 끌 수 있고, 크기는 `SFX_VOLUME`으로 정합니다.
- **읽어주기:** 말풍선을 브라우저 음성으로 읽습니다. 화면을 누르면 멈춥니다. 처음 누르기 전의 말풍선은 첫 터치 때 읽습니다. 지원하지 않는 브라우저에서는 버튼이 나오지 않습니다.
- **소리 확인:** 처음 누른 뒤 콘솔에 AudioContext 상태와 음성 목록이 한 번 나옵니다. 한국어 음성이 없으면 타이틀에 안내가 나오고, `VOICE_NOTE.show`로 끌 수 있습니다.

1. **상황 소개:** 하모가 옛 책 이야기와 "성 밖에 소식을 전해야 해!"를 한 줄씩 알려 줍니다.
2. **부품 찾기(60초):** 담장으로 나뉜 진주성 지도에서 움직입니다.
   - 빈 바닥을 누르면 그곳으로 걸어갑니다. 담장이 있으면 알아서 돌아갑니다.
   - 숨김 장소를 누르면 앞까지 걸어갑니다. 도착하면 빠르게 5번 눌러 뒤집니다. 다른 곳을 누르면 취소하고 그쪽으로 갑니다. 지나가기만 해서는 줍지 않습니다.
   - PC에서는 방향키로 움직이고, 가까이 가서 스페이스바나 Enter를 5번 눌러 뒤집니다.
   - 내용물은 판마다 섞입니다. 나온 부품은 [담기] 또는 [두고 가기]를 고릅니다. 두고 간 부품은 나중에 다시 담을 수 있습니다.
   - 옛 책 조각은 가방 칸을 차지하지 않습니다. 찾으면 기록 카드가 나오고, 읽는 동안 타이머가 멈춥니다.
   - 가방은 5칸입니다. 칸을 누르면 그 자리에 내려놓습니다.
   - 힌트 주는 마을 사람을 누르면 2초 동안 이야기하고, 이번 판의 실제 배치로 만든 힌트를 하나 줍니다. 들은 곳에는 표시가 남습니다(! 부품 있음, ✕ 비어 있음).
   - 3단계의 할머니와 대장장이 아저씨는 원하는 물건을 가방에 넣고 말을 걸면 2초 뒤에 바꿔 줍니다(항아리 → 한지, 솥 → 끈).
   - 3단계에서는 날아가는 한지(눌러서 잡기)와 끈을 문 닭(눌러서 쫓아가기)이 1~2번 나옵니다. 이벤트 부품은 보너스입니다.
   - 쇠를 담으면 20% 느려지고 아요 머리 위에 땀이 납니다.
   - [처음으로]를 누르면 확인 창이 뜨고 타이머가 멈춥니다. 확인 창을 그대로 두면 자동 리셋으로 타이틀로 돌아갑니다.
   - 부품을 찾는 동안에는 자동 리셋이 동작하지 않습니다.
3. **조립:** 모은 부품만 고를 수 있습니다.
   - 날개: 한지 1개 = 작은 날개, 2개 = 보통 날개, 3개 이상 = 큰 날개. 찢어진 한지는 0.5개로 칩니다.
   - 끈이 없으면 들어 올리는 힘이 0.85배가 됩니다.
   - 금 간 대나무만 있으면 들어 올리는 힘이 0.85배가 되고 비행 중에 흔들립니다. 튼튼한 대나무가 함께 있으면 튼튼한 것을 씁니다.
   - 몸통 재료가 없거나 한지가 1개에 못 미치면 비거를 만들 수 없어 다시 도전합니다.
4. **비행:** 쉬운 모드와 같은 계산에 조종과 상승 기류를 더합니다. 단계별 목표 깃발까지 가면 성공입니다.
5. **결과:** 실패하면 기존 설명에 도전 모드 한 마디가 더 나옵니다. 퀴즈에는 도전 모드 문제가 1개 더 들어갑니다.

모은 기록 카드는 타이틀의 [비거 기록 도감]에서 봅니다. 브라우저에 저장되어 날짜가 바뀌어도 남고, 자동 리셋으로도 지워지지 않습니다. 체험관에서 새로 시작하려면 브라우저 콘솔에서 `localStorage.removeItem('ayo-bigeo-records')`를 실행합니다.

결과 화면에는 다른 모드로 가는 버튼이 있습니다. 타이틀을 뺀 모든 화면 왼쪽 위에는 [처음으로] 버튼이 있습니다.

| 바꾸고 싶은 것 | 고칠 곳(data.js) |
|---|---|
| 단계별 기능, 목표 거리, 장소, 내용물 | `STAGES` |
| 발사·두드리기·상승 기류 수치 | `CONTROL` |
| 물물교환 | `TRADES`, `TRADE_THANKS` |
| 돌발 이벤트 | `EVENTS` |
| 처음 보는 요소 안내 | `TUTORIALS` |
| 조종 문구, 연속 찾기, 켜기·끄기 버튼 | `CONTROL_TEXT`, `STAGE_TEXT` |
| 가방 칸 수, 제한 시간 | `BAG_SIZE`, `TIME_LIMIT` |
| 뒤지기 누르는 횟수, 대화 시간 | `SEARCH_TAPS`, `TALK_TIME` |
| 금 간 대나무·찢어진 한지·끈 없음의 영향 | `STATE_EFFECT` |
| 걷는 속도, 무게 감속, 날개별 한지 수 | `CHALLENGE` |
| 숨김 장소 위치와 종류 | `HIDE_SPOTS`, `HIDE_SPOT_KINDS` |
| 부품 정보 | `ITEMS` |
| 옛 기록 카드, 도감 문구 | `RECORD_CARDS`, `RECORD_TEXT` |
| 건물, 장소 이름, 담장 | `MAP_PLACES`, `MAP_DECOR`, `MAP_FENCES` |
| 마을 사람 위치, 힌트 문장 | `VILLAGERS`, `HINT_TEMPLATES` |
| 소개와 안내 문구 | `CHALLENGE_STORY` |
| 실패 시 한 마디 | `CHALLENGE_FEEDBACK` |
| 깃발 이름 | `TEXT.goalFlag` |
| 시험용 배치 고정 | `CHALLENGE.fixedSeed`에 숫자를 넣습니다(평소에는 `null`) |

`HIDE_SPOTS`와 `VILLAGERS`의 `sx`, `sy`는 아요가 서는 자리입니다. 담장이나 건물 위에 두면 검사에서 문제로 나옵니다. `STAGES`의 `loot` 개수 합은 그 단계 `spots` 수와 같아야 합니다.

## 조합 검사(수치를 고친 뒤 필수)

1. 게임을 연 브라우저에서 `F12`를 눌러 콘솔을 엽니다.
2. `runAllCombos()`(쉬운 모드 자동 비행), `runChallengeCombos()`(도전 모드 단계별), `runControlTest()`(조종)를 입력하고 Enter를 누릅니다.
3. 조합별 결과가 표로 나오고, 맨 아래에 `검사 통과` 또는 문제 목록이 나옵니다.

검사하는 규칙은 다음과 같습니다.

- 쇠 몸통이나 뒤 무게추면 반드시 추락, 그 외에는 추락 없음
- 뒤 무게추일 때 추락 거리는 작은 날개 < 보통 날개 < 큰 날개
- 큰 날개 + 대나무 + 가운데가 가장 멀리 날고, 이 조합만 "최고 기록!"
- 앞 무게추와 작은 날개는 "조금 날았어"
- 같은 조합은 항상 같은 결과
- 추락은 남강에, 그 외에는 건너편 모래밭에 떨어짐
- 비행 시간 6초 이내
- (도전 모드) 단계별 대표 가방의 성공·실패와 피드백 우선순위, 잠금 규칙
- (도전 모드) 1단계는 대나무 + 한지 2장 이상이면 성공 가능
- (도전 모드) 단계별 내용물 수, 힌트가 실제 배치와 일치, 위치를 알면 어떤 배치든 60초 안에 최적 가방 가능
- (도전 모드) 이벤트는 3단계에만, 판마다 1~2개, 10~45초, 같은 시드면 같은 결과
- (도전 모드) 진행 중 문장 20자 이내
- (조종) 쇠 몸통·뒤 무게추는 어떤 조종이어도 강에 추락
- (조종) 최적 설계 + 최적 조종이 자동 비행보다 10~20% 더 멀리, 약 30도가 가장 멀리

## 동작 규칙

- **등급:** 추락이 아니면 거리로 나눕니다. 75m 미만 "조금 날았어", 112m 미만 "잘 날았어", 그 이상 "최고 기록!"입니다.
- **이번 판 기록:** 최근 5번을 막대 그래프로 보여 줍니다. 처음으로 돌아가면 지워집니다.
- **오늘의 최고 기록:** 쉬운 모드와 도전 모드를 따로 보여 줍니다. 브라우저에 저장되며 날짜가 바뀌면 초기화됩니다. 추락은 올리지 않고, 결과가 항상 같으므로 같은 조합은 한 번만 올립니다.
- **자동 리셋:** 60초 동안 입력이 없으면 타이틀로 돌아가고 이번 판 기록과 선택을 비웁니다.
- **이미지 대체:** 이미지가 없거나 불러오지 못하면 도형으로 대신 그리고 게임은 계속됩니다. 사진이 없으면 기존 그림 배경을 씁니다.
