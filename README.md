# 아요의 비거 날리기

진주 비거 체험관 제안용 교육 게임 데모입니다. 아이들이 5×3 칸에 부품을 놓아 비거를 조립하고 날려 봅니다. 구성에 따라 성능과 나는 방식이 달라지고, 무게중심과 양력 중심이 비행에 주는 영향을 체험합니다.

- **비거 만들기(스테이지 5개):** 한 판 1~2분. 스테이지마다 새 부품이 하나씩 나오고, 별 3개 미션이 있습니다.
- **도전 모드(진주성 60초):** 2~3분. 60초 동안 모은 부품이 그대로 조립 화면의 부품 상자가 됩니다.

외부 라이브러리와 인터넷 연결 없이 동작합니다(Canvas 2D).

## 파일 구성

| `assets/ayo.png` | 아요(하모 프렌즈의 삵) 이미지. 불러오지 못하면 도형으로 그립니다 |
| `assets/bg/` | 배경 사진(`title.jpg`, `story.jpg`, `flight.jpg`). 없으면 기존 그림 배경을 씁니다 |

## 로컬에서 실행하기

`index.html`을 더블클릭해서 Chrome이나 Edge로 열면 바로 실행됩니다.

체험관 PC에서는 전체 화면 키오스크로 띄우면 좋습니다.

```
chrome --kiosk "file:///C:/경로/bigeo/index.html"
```

## GitHub Pages로 배포하기

1. 저장소의 **Settings → Pages**로 들어갑니다.
2. **Source**를 `Deploy from a branch`로, **Branch**를 `main` / `(root)`로 고르고 **Save**를 누릅니다.
3. 1~2분 뒤 `https://계정이름.github.io/저장소이름/` 주소로 접속합니다.

모든 경로가 상대경로라서 따로 고칠 설정은 없습니다. GitHub Pages는 파일 이름의 대소문자를 구분하므로 이미지 파일 이름을 바꿀 때는 `data.js`와 똑같이 맞춰 주세요.

## 화면 흐름

- 비거 만들기: 타이틀 → 이야기 → 스테이지 고르기 → 스테이지 소개(새 부품 한 문장씩) → 조립 → 비행 → 결과(별 3개) → 퀴즈 → 망경공원 안내
- 도전 모드: 타이틀 → 단계 고르기 → 상황 소개 → 진주성 60초 부품 모으기 → 조립(모은 부품만) → 비행 → 결과 → 퀴즈
- 타이틀에서 비거 기록 도감으로 갈 수 있습니다. 타이틀을 뺀 모든 화면 왼쪽 위에는 [처음으로] 버튼이 있습니다.

## 조립

- 가로 5 × 세로 3 칸입니다. **오른쪽이 앞**입니다.
- 아래 부품 상자에서 칸으로 **끌어다 놓기**, 또는 부품을 **탭한 뒤 칸을 탭**해서 놓습니다(끌기가 어려운 아이용).
- 칸의 부품을 탭하면 상자로 돌아갑니다. 칸의 부품을 다른 칸으로 끌면 옮겨집니다(자리를 바꿈).
- 조종석(아요)은 꼭 하나 있어야 합니다. 부품은 위아래·옆으로 이어져 있어야 하고, 떨어진 부품은 흔들리며 하모가 안내합니다. 이때는 날릴 수 없습니다.
- 오른쪽 막대 3개: 무게, 뜨는 힘(무게보다 길면 초록), 미는 힘. 칸 위의 **빨간 점 = 무게중심**, **파란 세모 = 뜨는 힘의 중심**입니다. 무게중심이 어긋나면 칸 전체가 그쪽으로 살짝 기웁니다.
- [아요 추천]은 그 스테이지(도전 모드는 모은 부품)에 맞는 예시 조립을 한 번에 채웁니다.

### 부품(data.js `PARTS`)

| 부품 | 하는 일 |
|---|---|
| 조종석 | 아요가 탐. 꼭 1개 |
| 대나무 틀 | 가볍게 부품을 이음 |
| 한지 날개 | 뜨는 힘. 많을수록 잘 뜨지만 공기 저항도 커짐 |
| 무게추 | 무게중심 조절 |
| 회전날개 | 비행 중 화면을 두드릴수록 돌아서 위로 뜸(기존 '배 두드리기'를 여기로 연결) |
| 풀무 | 비행 중 버튼을 누르는 동안 앞으로 밂. 바람 게이지를 씀 |
| 수레바퀴 | 출발 언덕에서 더 빨리 굴러 나감 |
| 연 꼬리 | 흔들림을 줄임 |

## 비행

- 물리 엔진 없이 조립을 합산(무게, 날개 힘, 저항, 미는 힘, 무게중심, 양력 중심)해서 한 덩어리로 날립니다. 같은 조립·같은 조작이면 결과가 항상 같습니다.
- 무게중심이 양력 중심보다 앞이면 고개를 숙이고, 뒤면 고개가 들립니다. 많이 어긋나면 곤두박질칩니다.
- 날개형은 멀리 미끄러지듯, 회전날개형은 제자리에서 떠오르고 천천히, 풀무형은 빠르지만 금방 떨어집니다.
- **당겨서 쏘기:** 탈것을 누른 채 왼쪽으로 끌었다 놓습니다. 끈 길이가 세기, 아래로 기울이면 높게·위로 기울이면 낮게 쏩니다. 오른쪽으로 밀면 취소. 당기기를 시작한 손가락만 따라갑니다.
- 타이틀의 [자동 발사]를 고르면 비거 만들기에서 당기지 않아도 날아갑니다(어린 아이용). 도전 모드 1단계는 늘 자동 발사입니다.
- PC: 조준 중 위/아래 = 각도, 좌/우 = 세기, 스페이스 = 발사. 비행 중 스페이스 = 회전날개 두드리기, → 꾹 = 풀무.
- 결과 화면에서 하모가 원인을 한 문장으로 설명합니다(`FEEDBACK`).

## 스테이지(data.js `STAGES`)

| 스테이지 | 목표 | 새 부품 | 별 |
|---|---|---|---|
| 1. 언덕에서 출발 | 50m | 한지 날개·대나무 틀 | 도착 / 부품 2개 이하 / 별 상자 |
| 2. 남강 건너기 | 65m | 무게추(앞에 옮길 수 없는 짐) | 도착 / 부품 4개 이하 / 별 상자 |
| 3. 높이 떠오르기 | 56m 높이 | 회전날개 | 도착 / 부품 4개 이하 / 별 상자 |
| 4. 멀리 소식 전하기 | 100m | 풀무 | 도착 / 부품 5개 이하 / 별 상자 |
| 5. 자유 조립 | 100m | 수레바퀴·연 꼬리 | 도착 / 130m 넘기 / 별 상자 |

- 앞 스테이지를 깨면 다음 스테이지가 열립니다. 별 기록은 브라우저에 저장됩니다(`ayo-bigeo-stars`).
- **단체 체험용 설정:** 타이틀 로고를 빠르게 5번 누르면 메뉴가 나옵니다. [스테이지 모두 열기], 도전 모드 단계 고정, 진행·도감·별 지우기가 있습니다.

## 도전 모드: 진주성 60초

| 기능 | 1단계 | 2단계 | 3단계 |
|---|---|---|---|
| 숨김 장소 | 8곳 | 9곳(옛 책 1) | 12곳(옛 책 1) |
| 마을 사람 힌트 | 없음 | 1명 | 1명 |
| 물물교환 | 없음 | 없음 | 2명(항아리 → 한지 날개, 솥 → 풀무) |
| 돌발 이벤트 | 없음 | 없음 | 1~2개(날아가는 한지 날개, 연 꼬리를 문 닭) |
| 발사 | 자동 | 당겨서 쏘기 | 당겨서 쏘기 |
| 목표 거리 | 70m | 85m | 105m |

- 가방은 8칸이고, 조종석은 따로 늘 줍니다. 모은 부품이 그대로 조립 화면의 부품 상자가 됩니다.
- 1단계에는 한지 날개가 늘 4장 들어 있습니다(2장만 모아도 성공할 수 있음).
- 숨김 장소 내용물은 `LOOT_TABLE`, 단계 설정은 `CHALLENGE_LEVELS`에서 고칩니다.
- 빈 바닥을 누르면 걸어가고, 숨김 장소를 누르면 앞까지 가서 빠르게 5번 눌러 뒤집습니다. PC는 방향키와 스페이스/Enter.
- 무게추·수레바퀴·풀무·솥을 담으면 걸음이 느려집니다.

## 그 밖의 요소

- **소리:** 효과음은 코드로 만듭니다. 타이틀에서 끌 수 있고, 크기는 `SFX_VOLUME`입니다. 터치 기기에서는 손을 뗄 때 소리가 켜집니다.
- **읽어주기:** 말풍선을 브라우저 음성으로 읽습니다. 화면을 누르면 멈춥니다. 한국어 음성이 없으면 타이틀에 안내가 나옵니다(`VOICE_NOTE.show`).
- **처음 보는 요소 안내:** 손가락과 한 줄 안내가 나오고, 누르면 계속합니다(`TUTORIALS`).
- **자동 리셋:** 60초 동안 입력이 없으면 타이틀로 돌아갑니다(부품 모으는 중에는 동작하지 않음).
- **역사 문구:** 비거는 옛 책에 전해지는 이야기입니다. 게임 안의 설명은 "~라고 전해져", "~라고 적혀 있어"로 씁니다.

## data.js 수정 방법

메모장이나 VS Code로 `data.js`를 열어 고치고 저장한 뒤, 브라우저를 새로고침합니다. 따옴표와 쉼표는 지우지 마세요.

| 바꾸고 싶은 것 | 고칠 곳 |
|---|---|
| 부품 무게·힘·이름·소개 문장 | `PARTS` |
| 비행 느낌(날개 힘, 저항, 기울기, 풀무, 회전날개, 발사) | `CRAFT_FLIGHT` |
| 조립 화면 안내 문구 | `BUILD_TEXT` |
| 결과 화면 하모 설명 | `FEEDBACK` |
| 스테이지 목표·부품·별 조건·별 상자·아요 추천 | `STAGES`, `STAGE_MODE_TEXT` |
| 도전 모드 단계·목표 | `CHALLENGE_LEVELS` |
| 도전 모드 숨김 장소 내용물 | `LOOT_TABLE` |
| 도전 모드 물건 이름 | `ITEMS` |
| 가방 칸 수, 제한 시간 | `BAG_SIZE`, `TIME_LIMIT` |
| 물물교환, 돌발 이벤트 | `TRADES`, `EVENTS` |
| 당겨서 쏘기 | `CONTROL` |
| 이야기, 퀴즈, 장소 안내 | `STORY`, `QUIZ`, `PLACE_INFO` |
| 옛 기록 카드 | `RECORD_CARDS` |
| 배경 사진, 아요 크기 | `BG_PHOTOS`, `AYO_SIZE` |

## 검사(수치를 고친 뒤 필수)

1. 게임을 연 브라우저에서 `F12`를 눌러 콘솔을 엽니다.
2. 아래 함수를 입력하고 Enter를 누릅니다. 표가 나오고, 맨 아래에 `검사 통과` 또는 문제 목록이 나옵니다.

| 함수 | 검사 내용 |
|---|---|
| `runAllCombos()` | 대표 조립 23종 + 무작위 300종을 여러 각도·세기·조작으로 자동 비행. NaN, 무한 비행, 화면 밖 이탈, 매번 다른 결과가 없는지. 날개형/회전날개형/풀무형이 거리·높이·속도로 구분되는지. 무게중심이 어긋나면 덜 날고, 연 꼬리·수레바퀴가 도움이 되는지 |
| `runStageTest()` | 스테이지마다 '아요 추천' 조립으로 자동 발사·30° 당겨 쏘기 모두 깰 수 있는지, 별 3개를 한 번에 얻는 방법이 있는지, 조종석만으로는 못 깨는지 |
| `runChallengeCombos()` | 도전 모드 대표 가방의 성공·실패와 한 마디, 내용물 수, 1단계 보장, 힌트가 실제 배치와 일치, 위치를 알면 목표 가방을 60초 안에 모을 수 있는지, 이벤트, 진행 중 문장 20자 이내 |
| `runControlTest()` | 당기는 방향과 각도, 발사 각도·세기, 풀무 누르기, 회전날개 두드리기가 결과를 바꾸는지 |
