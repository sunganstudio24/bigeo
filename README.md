# 아요의 비거 날리기

진주 비거 체험관 제안용 교육 게임 데모입니다. 초등 1~3학년이 비거 부품을 골라 날려 보면서 날개 크기, 무게, 무게중심이 비행에 주는 영향을 체험합니다. 쉬운 모드는 한 판 1~2분, 도전 모드는 2~3분입니다.

외부 라이브러리와 인터넷 연결 없이 동작합니다.

## 파일 구성

| 파일 | 내용 |
|---|---|
| `index.html` | 시작 파일 |
| `style.css` | 버튼·글자·배치 |
| `game.js` | 게임 코드(화면별 함수: title / story / build / flight / result / quiz) |
| `data.js` | **문구와 수치 — 코드를 몰라도 여기만 고치면 됩니다** |
| `assets/hamo/` | 하모 이미지 |
| `assets/ayo.png` | (선택) 아요 이미지. 지금은 없어서 도형으로 그립니다 |

## 로컬에서 실행하기

`index.html`을 더블클릭해서 Chrome이나 Edge로 열면 바로 실행됩니다.

체험관 PC에서는 전체 화면 키오스크로 띄우면 좋습니다.

```
chrome --kiosk "file:///C:/경로/ayo-bigeo/index.html"
```

## GitHub Pages로 배포하기

1. GitHub에서 새 저장소를 만들고 이 폴더의 파일을 모두 올립니다. `index.html`이 저장소 맨 위에 있어야 합니다.
2. 저장소의 **Settings → Pages**로 들어갑니다.
3. **Source**를 `Deploy from a branch`로, **Branch**를 `main` / `(root)`로 고르고 **Save**를 누릅니다.
4. 1~2분 뒤 `https://계정이름.github.io/저장소이름/` 주소로 접속합니다.

모든 경로가 상대경로라서 따로 고칠 설정은 없습니다. GitHub Pages는 파일 이름의 대소문자를 구분하므로 이미지 파일 이름을 바꿀 때는 `data.js`와 똑같이 맞춰 주세요.

## data.js 수정 방법

메모장이나 VS Code로 `data.js`를 열어 고치고 저장한 뒤, 브라우저를 새로고침합니다. 따옴표와 쉼표는 지우지 마세요.

| 바꾸고 싶은 것 | 고칠 곳 |
|---|---|
| 이야기 화면 하모 대사 | `STORY.speech` |
| 역사 설명(체험관 자료 확인 후 추가) | `STORY`에 `history: '문장',` 줄을 넣으면 말풍선 아래에 나옵니다 |
| 조립 화면 첫 선택값 | `CONFIG.defaults` |
| 결과 화면 하모 대사 | `FEEDBACK` |
| 퀴즈 문제 추가·수정 | `QUIZ` |
| 상황별 하모 이미지 | `HAMO_IMG` |
| 버튼·제목 등 나머지 문구 | `TEXT`, `GRADE_TEXT` |
| 날개·몸통 수치 | `CONFIG.wings`, `CONFIG.bodies` |
| 비행 느낌(속도, 하강, 뒤집힘) | `CONFIG.flight` |
| 등급을 나누는 거리 | `CONFIG.grades` |
| 자동 리셋 시간 | `CONFIG.idleResetSeconds` |

수치를 바꾼 뒤에는 아래 검사를 꼭 다시 실행하세요.

## 도전 모드: 진주성 60초

타이틀에서 모드를 고릅니다. 쉬운 모드는 기존 게임 그대로이고, 도전 모드는 60초 동안 부품을 직접 모아 비거를 만드는 모드입니다. 한 판은 2~3분입니다.

1. **상황 소개:** 하모가 "성 밖에 소식을 전해야 해!"라고 알려 줍니다.
2. **부품 모으기(60초):** 진주성 지도에서 화면을 누른 곳으로 아요가 걸어갑니다(PC는 방향키도 가능). 부품에 닿으면 가방에 담깁니다.
   - 가방은 5칸입니다. 칸을 누르면 그 자리에 내려놓습니다. 다른 부품에 닿은 채 내려놓으면 바꾸기가 됩니다.
   - 쇠·항아리·솥은 하나당 20%씩 느려집니다(최소 40%). 무거우면 아요 머리 위에 땀이 납니다.
   - 항아리·솥은 비거에 쓸 수 없는 함정입니다.
   - 이 단계에서는 자동 리셋이 동작하지 않습니다.
3. **조립:** 모은 부품만 고를 수 있습니다.
   - 날개: 한지 1개 = 작은 날개, 2개 = 보통 날개, 3개 이상 = 큰 날개
   - 끈이 없으면 들어 올리는 힘이 0.85배가 됩니다.
   - 몸통 재료나 한지가 하나도 없으면 비거를 만들 수 없어 다시 도전합니다.
4. **비행:** 쉬운 모드와 같은 계산을 씁니다. 100m 지점의 깃발까지 가면 성공입니다.
5. **결과:** 실패하면 기존 설명에 도전 모드 한 마디가 더 나옵니다. 퀴즈에는 도전 모드 문제가 1개 더 들어갑니다.

| 바꾸고 싶은 것 | 고칠 곳(data.js) |
|---|---|
| 가방 칸 수, 제한 시간, 목표 거리 | `BAG_SIZE`, `TIME_LIMIT`, `SUCCESS_DISTANCE` |
| 걷는 속도, 무게 감속, 끈 없을 때 배율, 날개별 한지 수 | `CHALLENGE` |
| 장소 위치와 이름 | `MAP_PLACES`, `MAP_DECOR` |
| 부품 이름·위치·무게·용도 | `ITEMS` |
| 소개와 안내 문구 | `CHALLENGE_STORY` |
| 실패 시 한 마디 | `CHALLENGE_FEEDBACK` |
| 깃발 이름 | `TEXT.goalFlag` |

부품은 건물과 가운데 길 사이에 두어야 합니다. 건물 뒤에 두면 아요가 곧장 걸어가다 막힐 수 있습니다.

## 조합 검사(수치를 고친 뒤 필수)

1. 게임을 연 브라우저에서 `F12`를 눌러 콘솔을 엽니다.
2. `runAllCombos()`(쉬운 모드)와 `runChallengeCombos()`(도전 모드)를 입력하고 Enter를 누릅니다.
3. 조합별 결과가 표로 나오고, 맨 아래에 `검사 통과` 또는 문제 목록이 나옵니다.

검사하는 규칙은 다음과 같습니다.

- 쇠 몸통이나 뒤 무게추면 반드시 추락, 그 외에는 추락 없음
- 뒤 무게추일 때 추락 거리는 작은 날개 < 보통 날개 < 큰 날개
- 큰 날개 + 대나무 + 가운데가 가장 멀리 날고, 이 조합만 "최고 기록!"
- 앞 무게추와 작은 날개는 "조금 날았어"
- 같은 조합은 항상 같은 결과
- 추락은 남강에, 그 외에는 건너편 모래밭에 떨어짐
- 비행 시간 6초 이내
- (도전 모드) 대나무1 + 한지3 + 끈1 + 가운데는 반드시 성공, 한지2는 성공 또는 목표 근처
- (도전 모드) 쇠 몸통이나 뒤 무게추는 어떤 날개·끈이어도 실패
- (도전 모드) 실패 시 한 마디의 우선순위, 잠금 규칙, 무게별 속도

## 동작 규칙

- **등급:** 추락이 아니면 거리로 나눕니다. 75m 미만 "조금 날았어", 112m 미만 "잘 날았어", 그 이상 "최고 기록!"입니다.
- **이번 판 기록:** 최근 5번을 막대 그래프로 보여 줍니다. 처음으로 돌아가면 지워집니다.
- **오늘의 최고 기록:** 쉬운 모드와 도전 모드를 따로 보여 줍니다. 브라우저에 저장되며 날짜가 바뀌면 초기화됩니다. 추락은 올리지 않고, 결과가 항상 같으므로 같은 조합은 한 번만 올립니다.
- **자동 리셋:** 60초 동안 입력이 없으면 타이틀로 돌아가고 이번 판 기록과 선택을 비웁니다.
- **이미지 대체:** 이미지가 없거나 불러오지 못하면 도형으로 대신 그리고 게임은 계속됩니다.
